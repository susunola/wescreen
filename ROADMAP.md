# Product roadmap

## Product promise

The fastest trustworthy way for an Edge user to create and keep a screen recording locally. Privacy, predictable capture, and recoverability come before cloud collaboration.

## Now — v0.2

- [x] Local screen/window/tab capture, audio mix, recovery, preview, quality controls, and bilingual documentation.
- [ ] Surface a clear action status, long-recording storage warning, and complete UI localization.

## Next — v0.3: Link-assisted tab recording

- [ ] URL input, recent links, duration presets, and an open-target action.
- [ ] Guide the user to make one explicit capture confirmation in the target tab.
- [ ] Store optional schedules locally and notify when a recording needs confirmation.
- [ ] Do not implement silent capture: Chromium requires user invocation for tab recording.

## Later — v0.4: Better tutorials

- [ ] Camera picture-in-picture, cursor/click indicators, area selection, and simple annotations.
- [ ] Post-record trim/re-export; add MP4/GIF only after an in-browser encoding path is validated.

## Release — v1.0

- [ ] Complete Edge Add-ons submission, privacy disclosure, regression matrix, and production screenshots.
