# WeScreen 1.20.0：均衡修复与 Telegram Web

智能最佳保持原视频音频和时钟。处理返回超过当前画面 150 ms 时回到原画，避免旧 AI 画面覆盖新进度；暂停、拖动和跨段会使旧请求失效。高清及桌面文字保护仍沿用 1.19 的原尺寸保护。实时引擎仍为 FSRCNN 回退，并非新因果模型或 CoreML 模型。

清晰人声仅对选中的系统/标签页音轨做温和 EQ：70 Hz 高通、250 Hz -2 dB、2500 Hz +1.5 dB。默认关闭；音乐档关闭它及麦克风降噪。它不重建丢失频率，不是 AI 音频模型。独立音轨保存未经混音处理的源轨。录制时切换处理选项需下一次录制才生效。

Telegram 消息链接用于归类和核对，不通过私有 API 下载、不绕过频道权限。公开频道用用户名，私有频道用数字身份，消息 ID 必须配合频道。名称是可修改的本地标签，不要求复制 Telegram 标题。

视频区域/缓冲/结束检测依赖网页 DOM、目标视频及频道身份都能核对。版本结构不匹配时保持完整标签页与手动停止。区域模式下核对丢失会暂停；恢复只能继续自动暂停的录制，不能覆盖手动暂停。摄像头合成保持原路径，不同时自动裁区域。固定输出尺寸保持比例；录前在源页全屏可提高有效采集像素。

抽样验收最多约 24 个计划采样点（分段至少两个），20 秒预算；超时记为部分检查。相邻样本近黑或近相同时给可疑时间区间，可能是正常镜头或画面，需人工检查。源声音监测独立于麦克风；无明显信号只提示，不能断定视频无声。原录像和各次重录独立保留；只将同一录制会话的安全分段连续播放。

升级应更新相同扩展 ID 的原目录。卸载扩展会删除浏览器数据；本次不更改数据库版本，不移动或删除历史视频。
