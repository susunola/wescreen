# WeScreen 1.18.0 · 录制、播放与声音质量

## 已落实

| 范围 | 行为 |
| --- | --- |
| 分辨率 | 横/竖屏分别按长短边限制；1080p 可保留 1920×1080 或 1080×1920；低分辨率不放大 |
| 帧率 | 来源帧率与 24/25/30/50/60 可选；手动选择同时设置采集理想值与上限，实际值以采集轨道为准 |
| 编码码率 | 按像素、帧率、文字/运动场景计算；8K 不再提前沿用 4K 限幅，设置设备负载保护上限 |
| 测量 | 目标码率、编码器报告、实际成片平均码率分开；成片平均包含声音和容器，采集帧率不冒充编码后逐帧统计 |
| 录音 | 192 kbps 人声、256 kbps 音乐；音乐选项关闭麦克风人声 DSP，系统声音不降噪；保留采样率和立体声混音 |
| 声音保真 | 画质处理保留兼容 AAC/ALAC/MP3 压缩包；其他音轨为 MP4 兼容转 AAC 256 kbps；声音修复仍单独启用 |
| 输出保护 | 录制可关闭的压缩器与采样峰值上限；播放增强模式有峰值保护，原声模式旁路限幅 |
| 音量均衡 | 播放以 RMS 测量做缓慢、有界增益调整，静音不抬升；离线声音修复保持两遍 LUFS 归一化 |
| 同步 | 小偏差用有限播放速率调整，大偏差重定位；暂停、拖动与缓冲关闭独立音轨输出；倍速保留音调 |
| 画质处理 | 桌面文字减少降噪/锐化；运动画面减少时间降噪；SeedVR2 输入准备无损编码；保留 SDR 色彩标记 |
| HDR | 默认拒绝静默 SDR 化；主动选择 HDR 转 SDR，检测 zscale 支持，输出 BT.709 副本，原文件保留 |
| 实时 AI | 新增强包使用 PNG 输入/输出，避免两次 JPEG 损失；旧包兼容 JPEG；晚到帧丢弃、过慢回退原画 |
| 连续播放 | 同一录像分段保持 AI 选择；读取采用最多 3 项缓存，删除时失效、换段验证录像是否仍存在 |
| 定位 | 拖动只预览目标、释放提交一次；点击恢复播放，缩略图独立解码；记录目标帧响应耗时，取消过期 AI 请求 |
| 观看 | 既有完整画面/裁切、旋转、缩放、真全屏和每视频记忆继续保留；逐帧默认采用记录的采集/处理帧率 |
| 长录制 | 预览停帧/掉帧、连续无声、削波、空间不足、写入延迟提示；恢复片段与磁盘同步继续工作 |

## 实际边界

实时 AI 仍使用单帧 FSRCNN，PNG 去掉传输损失，但没有新增时序神经模型或 WebGPU/CoreML 推理。晚到帧回退原画，不能保证所有设备实时达到最高质量。跨段缓存减少读取等待，当前仍切换 HTMLVideoElement 来源，不承诺所有编码格式无缝。

在线均衡为 RMS 增益控制，峰值保护为采样峰值保护，不宣称经过响度认证的实时 LUFS/真峰值限制器。离线 LUFS 使用原有两遍分析。真实设备 4K/8K 编码上限与两小时以上稳定性需在目标设备进行长录制测试；本轮没有用短片宣称这些长期指标通过。

## 更新与测试

扩展覆盖原目录并重新加载原条目，商店版更新同一条目；不要卸载或换扩展 ID。数据库名称与版本保持 `wescreen` / 4。增强包保留 `.runtime`、`.venv` 与 `models`。Mac 已安装 FFmpeg full，增强程序自动优先使用该独立版本，普通 FFmpeg 同时更新到兼容依赖的 9.0.2。

测试建议：先录制文字与快速运动画面，核对实际尺寸、帧率和码率；音乐档位录立体声；拖动并跨段播放；选择智能最佳；HDR 文件先短预览再另存。比较增强时可按住原画对比，原文件继续保留。
