连接本机处理程序

录屏与录像库可以直接使用。裁剪、剪头尾和增强需要在同一台电脑启动一个独立程序，视频不上传云端。

  1. 下载 WeScreen 源码或独立 helper 包并解压；安装 Python 3.10–3.13 和 FFmpeg。
  2. 在解压目录运行 bash enhancement/start.sh，macOS 也可双击 enhancement/start.command。
  3. 回到 WeScreen，画质增强会自动连接，无需寻找密钥。请使用与扩展配套的 1.17.0 或更新本机程序包。
  4. 自然修复和裁剪可直接使用。强力 AI 需另运行 bash enhancement/install-seedvr.sh，下载约 7 GB 模型，安装后再检测。

强力模型较慢，请先预览实际片段；完整结果保留到主动删除，保存失败时可在“处理任务”重试或直接导出。

更换扩展后无法自动连接？

更新增强包后，在 Mac 双击 enhancement/install-launcher.command 更新本机启动器。回到扩展点击“自动连接”，在本机确认窗口核对扩展 ID 并允许连接。新旧扩展 ID 均可保留，不必重置旧配对。已有录像、处理结果和模型保留；后台重连不会弹出授权窗口。

Connect the local processing helper

Recording and Library work without a helper. Crop, trim and enhancement require a separate process on the same computer. Videos are never uploaded to a cloud processor.

  1. Download/extract the repository or helper package. Install Python 3.10–3.13 and FFmpeg.
  2. Run bash enhancement/start.sh from the extracted directory, or open enhancement/start.command on macOS.
  3. Return to WeScreen: enhancement connects automatically, without entering a token. Use the matching 1.17.0 or newer helper.
  4. For optional strong AI, run bash enhancement/install-seedvr.sh separately (about 7 GB of models), then check availability again.

Preview before using strong AI. Full results remain on this device until deleted; retry saving or export from Processing tasks.

Connection blocked after reinstalling?

After updating the helper, run enhancement/install-launcher.command on Mac. Click Auto connect in the extension, check its ID in the native local confirmation window, and allow it. New and previous IDs remain approved; no pairing reset is needed. Videos, results and models are preserved. Background reconnect never opens the approval window.

脸部修复 · CodeFormer / Face restoration

先启动基础增强包，再双击 enhancement/install-face.command（或运行 bash enhancement/install-face.sh）。需要 Python 3.11–3.12，下载约 545 MB 模型和 PyTorch 依赖。安装后重新连接；在播放器“工具 → 脸部修复”先预览、确认，再另存整段。

这是一种生成式脸部修复，不能可靠逆转重马赛克或完全遮挡，也没有跨帧真实人脸参考重建。可能改变五官或产生闪烁；检测不到可用的脸时会明确失败。CodeFormer 使用 S-Lab 非商业许可证，商用需向模型作者取得授权。模型与依赖由用户选择安装，不随扩展分发。

Run enhancement/install-face.command after starting the basic helper. Requires Python 3.11–3.12 and approximately 545 MB of weights plus PyTorch dependencies. Reconnect, preview, then confirm full processing. Generative restoration can change facial features or flicker and cannot reliably reverse heavy masking.
